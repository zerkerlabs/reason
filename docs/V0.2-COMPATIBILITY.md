# Reason 0.2 downstream compatibility

This report pins the downstream contracts checked during 0.2 release preparation. It is compatibility evidence, not a claim that every downstream deployment is upgraded.

## Core compatibility

The 0.2 conformance corpus replays the 0.1 exact-action request, certificate, bundle, verification, status, exit-code, request-digest, and reasoning-result-digest behavior. Gateway-bound and Rakhshak-bound fixtures verify through the same atomic command. Existing `zerker.reason.action.v1`, authorization, and bundle identifiers remain unchanged.

## Required rollout behavior

- Query `reason --format json capabilities` before enabling a new installed binary.
- Require the exact schemas used by the adapter.
- Replay `conformance/v1/manifest.json` in downstream CI.
- Keep authenticated context, replay consumption, network destination checks, memory promotion, and receipt signing in their owning products.
- Fail closed if the dedicated Treeship adapter is unavailable or any verifier disagrees.

Reason 0.2 is not published merely because this report exists. Release tags, archives, deployment, and downstream rollout require separate operator action.
